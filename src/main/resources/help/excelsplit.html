## Zusammenfassung Excel Split wandelt Excel-Masterdateien (.xlsx) in CSV-Templates um. Jede Masterdatei enthält auf Sheet 2 einen Template-Namen und -Wert, die automatisch in die Daten auf Sheet 1 eingetragen werden.

Typischer Einsatz:
Aus einer Vorlage (z.B. Kostenattribute, Konfigurationstabellen) werden vorbefüllte CSV-Dateien erzeugt, die anschließend per SQL-Loader oder anderem Import-Tool in die Zieldatenbank geladen werden können. Mehrere Masterdateien werden in einem Durchlauf verarbeitet. ## Felder Masterdateien (Ordner):
Verzeichnis mit den .xlsx-Quelldateien. Standardmäßig der master/-Ordner im Projektverzeichnis. Über "..." kann ein anderer Ordner gewählt werden.

Dateiliste (Checkboxen):
Alle gefundenen .xlsx-Dateien werden aufgelistet. Per Checkbox auswählen, welche Dateien verarbeitet werden sollen.
• "Alle an/ab" – schnelles An-/Abwählen aller Dateien
• "Aktualisieren" – Dateiliste neu laden

Ausgabeverzeichnis:
Zielordner für die erzeugten CSV-Dateien. Über "..." kann ein anderer Ordner gewählt werden. Vorhandene CSV-Dateien im Zielordner werden vor der Verarbeitung automatisch gelöscht. ## Aufbau der Excel-Dateien Jede Masterdatei (.xlsx) muss zwei Sheets enthalten:

Sheet 2 – Template-Informationen (Zeile 1):
• Spalte A: Template-Name → wird als CSV-Dateiname verwendet
• Spalte B: Template-Wert → wird in Sheet 1, Spalte E, Zeile 2 eingetragen
• Zeilen ab Zeile 2 werden ignoriert

Sheet 1 – Daten:
• Zeile 1: Kopfzeile (bleibt unverändert)
• Spalte C: Template-Name wird automatisch in jede Datenzeile eingetragen
• Spalte E, Zeile 2: Template-Wert aus Sheet 2, Spalte B ## Ausgabe CSV-Dateien:
Pro Masterdatei wird eine CSV-Datei im Ausgabeverzeichnis erzeugt. Der Dateiname entspricht dem Template-Namen aus Sheet 2. Trennzeichen ist das Semikolon (;).

validierung.log:
Im Ausgabeverzeichnis wird eine Log-Datei erstellt mit dem Ergebnis je verarbeiteter Datei (OK / Warnung / Fehler) inklusive Zeilen- und Spaltenanzahl.

Explorer:
Nach erfolgreicher Verarbeitung wird der Ausgabeordner automatisch im Windows Explorer geöffnet.

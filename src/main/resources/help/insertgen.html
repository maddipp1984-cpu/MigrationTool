## Zusammenfassung Der INSERT Generator erstellt Oracle INSERT-Scripts für beliebige Zieltabellen. Die Daten werden direkt in einer Tabelle im Tool erfasst oder per Ctrl+V aus Excel eingefügt. Pro Zieltabelle kann ein Preset mit Spaltenstruktur und Daten gespeichert werden.

Typischer Einsatz:
Kleinere Datenmengen (Lookup-Tabellen, Konfigurationswerte, Stammdaten) manuell pflegen und als fertiges SQL-Script exportieren. Unterstützt Sequences für automatische IDs und FK-Subselects für Verweise auf andere Tabellen. Jedes INSERT enthält eine WHERE NOT EXISTS-Prüfung, sodass das Script mehrfach ausführbar ist ohne Duplikate zu erzeugen. ## Preset-Verwaltung Preset (Dropdown):
Gespeicherte Konfigurationen laden. Jedes Preset speichert Zieltabelle, Spaltenstruktur, Daten, PK-Spalte, Sequence und FK-Subselects. Presets werden als CSV-Dateien unter config/insertgen/ gespeichert.

Preset speichern:
Aktuelle Tabelle als Preset speichern. Beim Speichern wird ein Name abgefragt. Existiert das Preset bereits, wird nachgefragt ob es überschrieben werden soll.

Preset löschen:
Das aktuell gewählte Preset unwiderruflich löschen. ## Felder Zieltabelle:
Name der Oracle-Zieltabelle, in die eingefügt werden soll (z.B. MY_TABLE). Pflichtfeld – wird für die Script-Generierung und den Dateinamen benötigt.

PK-Spalte (Dropdown):
Optionale Auswahl der Primärschlüssel-Spalte. Wird gold/fett im Spaltenheader hervorgehoben. In Kombination mit einer Sequence wird der PK-Wert durch SEQ.NEXTVAL ersetzt und aus der WHERE NOT EXISTS-Prüfung ausgenommen.

Sequence:
Optionaler Name der Oracle-Sequence (z.B. MY_SEQ). Nur relevant wenn eine PK-Spalte gewählt ist. Im generierten Script wird SEQUENCE.NEXTVAL statt des Literalwerts verwendet. ## Tabelle bearbeiten Spalten hinzufügen:
Über den ➕-Button wird eine neue Spalte mit frei wählbarem Namen angelegt.

Spalte umbenennen:
Doppelklick auf den Spaltenheader öffnet einen Dialog zum Umbenennen.

Spalten verschieben:
Spalte durch Klick auf den Header auswählen (wird blau hinterlegt), dann mit ◀ / ▶ nach links/rechts verschieben. Die Reihenfolge bestimmt die Spaltenreihenfolge im INSERT-Script.

Spalte/Zeilen löschen:
"Spalte löschen" entfernt die aktuell ausgewählte Spalte. "Zeilen löschen" entfernt die in der Tabelle markierten Zeilen.

Daten einfügen (Ctrl+V):
Tabellarische Daten aus Excel oder anderen Quellen einfügen. Bei leerer Tabelle wird gefragt, ob die erste Zeile die Spaltenüberschrift ist. Bei bestehender Tabelle wird ab der Cursor-Position eingefügt. ## FK-Subselects FK mit Subselect definieren:
Rechtsklick auf einen Spaltenheader → "FK mit Subselect". Im Dialog einen SQL-Subselect eingeben, z.B.:
SELECT ID FROM OTHER_TABLE WHERE NAME = {WERT}

Platzhalter {WERT}:
Wird pro Zeile durch den Zellwert ersetzt. Zahlen werden ohne Anführungszeichen eingesetzt, Texte mit einfachen Anführungszeichen. Klammern werden automatisch ergänzt falls nicht vorhanden.

Header-Markierung:
FK-Spalten werden hellblau + kursiv im Header dargestellt.
PK-Spalten werden gold + fett dargestellt. ## Script-Generierung "Script generieren":
Erzeugt ein Oracle-SQL-Script mit folgender Struktur:

DELETE FROM <tabelle>;

Pro Datenzeile:
INSERT INTO <tabelle> (spalten...)
SELECT werte... FROM DUAL
WHERE NOT EXISTS (SELECT 1 FROM <tabelle> WHERE bedingungen...);

Besonderheiten:
• PK mit Sequence: SEQ.NEXTVAL statt Literalwert, PK nicht in WHERE NOT EXISTS
• FK-Spalten: Subselect statt Literalwert
• Leere Zellen: NULL
• Ausgabe: <output-dir>/<TABELLENNAME>.sql ## Speichern "Speichern"-Button:
Überschreibt das aktuell gewählte Preset mit dem aktuellen Tabelleninhalt. Ist kein Preset gewählt, wird "Preset speichern" aufgerufen.

Änderungserkennung:
Bei ungespeicherten Änderungen wird der Speichern-Button blau hervorgehoben.
